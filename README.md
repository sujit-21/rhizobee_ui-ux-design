# Rhizobee Innovations — UI & UX Design

Modern, responsive, corporate web application for **Rhizobee Innovations Private Limited** — a digital payment solutions provider delivering payment gateways, QR code payments, Soundbox solutions, POS terminals, and PPI wallet infrastructure.

---

## 🚀 Key Features & Highlights

- **Corporate Design System**:
  - Official corporate color palette featuring deep trust blues (`#002b49`), vibrant brand blues (`#0284c7`, `#0369a1`), crisp neutral backgrounds, and gold accents (`#f59e0b`).
  - Human-centric, polished typography using Google Fonts (**Plus Jakarta Sans** and **Inter**).
  - High-clarity micro-interactions, responsive navigation, and accessible contrast ratios.

- **Responsive & Device-Justified Layouts**:
  - Fluid `clamp()` typography across all screen resolutions (from 320px mobile to 4K displays).
  - Single-line responsive headings with `white-space: nowrap !important` preventing awkward orphan word breaks.
  - Balanced, justified multi-line paragraph descriptions (`text-wrap: balance`).

- **Services & Solutions Showcase**:
  - Payment Gateway Solutions
  - QR Code Payments (Static & Dynamic)
  - Soundbox 4G Voice Confirmation
  - Smart Android POS Devices & Terminals
  - PPI Wallet & Prepaid Card Infrastructure
  - Brand Gift Cards & Employee Rewards
  - Zoompe — Dedicated Retailer & CSP Banking Portal
  - Switch & Core Payments API

---

## 🛠️ Technology Stack

- **Framework**: React 19 + Vite 8
- **Styling**: Vanilla CSS Design Tokens + Bootstrap 5.3 Grid Utilities + Bootstrap Icons
- **Routing**: React Router DOM v7
- **Linter**: Oxlint (0 errors, 0 warnings)

## 💻 Getting Started Locally

### Prerequisites
- Node.js (v18+ recommended)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/sujit-21/rhizobee_ui-ux-design.git

# Navigate into the project folder
cd rhizobee_ui-ux-design

# Install dependencies
npm install

# Start the Vite development server
npm run dev
```

The app will be available at `http://localhost:5173/`.

### Production Build

```bash
# Build production bundle
npm run build

# Preview production build locally
npm run preview
```
